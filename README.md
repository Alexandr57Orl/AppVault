# AppVault

Локальный демонстрационный каталог архивных приложений на React + TypeScript + Vite. Бэкенд и реальные файлы приложений отсутствуют. Метаданные, оценки и история доступности — моковые данные, а не подтверждённая информация App Store.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite (обычно http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

Сборка находится в `dist`.

## Структура проекта

```text
src/
  App.tsx                 # Общие состояния, переключение разделов и композиция
  main.tsx                # Точка входа React
  pages/
    LibraryPage.tsx       # Страница каталога и избранного
  components/
    layout/               # Шапка, боковое меню, подвал и информационный блок
    catalog/              # Карточки, фильтры, подборка, приветственный блок
    modals/               # Содержимое окна приложения и окна «О проекте»
    ui/Modal.tsx          # Общая оболочка диалога
  hooks/
    useFavorites.ts       # Избранное и синхронизация с localStorage
    useCatalog.ts         # Поиск, категории и сортировка
    useModal.ts           # Фокус, Escape, Tab и блокировка прокрутки
  data/apps.ts            # Моковые данные приложений
  constants/catalog.ts    # Категории каталога
  types/app.ts            # Типы приложения, раздела и сортировки
  styles/global.css       # Стили и адаптивная верстка
```

`App` хранит общие состояния: выбранный раздел, открытое окно, мобильное меню и избранное. Он передаёт данные и обработчики странице и компонентам через типизированные props. `LibraryPage` использует `useCatalog` для своих фильтров. Каталог и избранное используют одну страницу; при переключении раздела фильтры сбрасываются. `Modal` управляет доступностью диалога через `useModal`, а содержимое получает через `children`.

Для единообразного оформления кода: `npm run format`. Проверка форматирования: `npm run format:check`.

Поиск работает по названию и разработчику. Есть фильтры по категориям, сортировка по рейтингу, году и названию, подробные карточки и избранное в localStorage. Для проверки: найдите Flappy, выберите «Игры», добавьте приложение в избранное и обновите страницу — выбор должен сохраниться. На мобильных устройствах меню открывается кнопкой в шапке. Карточка закрывается клавишей Escape.

Иконки приложений стилизованы с помощью символов и CSS. Шрифт Manrope загружается из Google Fonts; без сети используется Arial.

# Тема и подписки

Переключатель в шапке меняет светлую и тёмную темы. При первом посещении используется
системная тема, выбор сохраняется в `localStorage`. Анимации учитывают `prefers-reduced-motion`.

В разделе «Подписки» доступны демонстрационные тарифы Explorer, Vault Plus и годовой Plus.
Цены — примеры. Выбор сохраняется локально, реальных списаний и подписки на сервере нет.
Explorer сбрасывает демо-доступ Plus. Карточка приложения предлагает перейти к тарифам,
а при выбранном Plus показывает доступность файла.

Для подключения установочных файлов предусмотрено поле `downloadUrl` в `AppEntry`.
Сейчас файлов нет. Перед запуском платных скачиваний необходимы учётные записи,
платёжный провайдер, серверная проверка подписки и защищённые ссылки на файлы:
проверка в интерфейсе сама по себе не защищает доступ.

## Вход и регистрация

Кнопка «Войти» в шапке открывает формы входа и регистрации. Реализованы проверка email,
минимальной длины пароля, имени и совпадения паролей, переключение видимости пароля,
демонстрационный профиль и выход. Окно поддерживает Escape и управление фокусом.
Это интерфейс без серверной авторизации: пароль не сохраняется и не проверяется по базе.
Профиль хранится только в памяти до обновления страницы. Избранное и тариф остаются
локальными данными браузера. Для реальной авторизации необходимо подключить сервер.
